# interactive-venue-ticketing
A responsive, interactive front-end web application for exploring venue, inspecting seat pricing, and managing a ticket shopping cart.

## Project Overview

"E-Ticket" (featuring the "Emin's Talks" event) allows users to navigate an interactive auditorium seating map. Users can pan, zoom, inspect individual seats to see pricing and location details, and they can send these tickets to shopping cart by clicking "Add To Cart" button.
